⚡ Консольные команды autoexec.cfg

Откройте консоль (кнопка ~) или создайте файл autoexec.cfg в папке Steam\steamapps\common\dota 2 beta\game\dota\cfg. Скопируйте команды ниже:

// === Dota 2 FPS Boost 2026 === r_canvas_major_framebuffer 0 ; Отключает лишние буферы r_canvas_minor_framebuffer 0 ; Экономит VRAM r_render_use_compressed_pools 1 ; Сжатие текстур в памяти r_deferred_additive_pass 0 ; Отключает сложное освещение r_deferred_specular 0 ; Отключает блики r_deferred_specular_bloom 0 ; Отключает bloom (засветы) r_fast_fog 1 ; Упрощенный туман cl_globallight_shadowmode 0 ; Отключает глобальные тени cl_forcepreload 1 ; Предзагрузка ресурсов (снижает лаги) fps_max 240 ; Ограничение FPS (под ваш монитор)

💡 Важно: Если игра вылетает — удалите r_canvas_* команды (они новые, работают не на всех видеокартах).

🚀 Параметры запуска Steam

В библиотеке Steam → ПКМ по Dota 2 → Свойства → Параметры запуска. Вставьте строку:

-novid -console -nojoy -nopreload -high -map dota -vulkan (или -dx11) -threads 8 -maxmem_1080 4096

📌 Что значат флаги:

  • -novid — пропуск заставки Valve.
  • -console — включает консоль (~).
  • -nojoy — отключает поддержку джойстиков.
  • -high — высокий приоритет процесса (CPU).
  • -vulkan — API Vulkan (даёт +10–20% FPS на новых драйверах). REC
  • -threads 8 — число ядер процессора (измените под своё).

⚠️ Vulkan требует установленного Vulkan Runtime (официальный сайт).

🖥️ Настройки Windows и видеокарты

⚙️ Windows (отключить лишнее):

  • Отключить Запись игр (Xbox Game Bar) и Режим игры (он иногда вредит).
  • Включить Высокую производительность в настройках электропитания.
  • Отключить визуальные эффекты Windows (Настройки → Спецвозможности → Визуальные эффекты → Отключить анимации).

🎮 Для NVIDIA:

  • В панели управления NVIDIA → Управление параметрами 3D:
    • "Предпочтительный режим электропитания" → Максимальная производительность.
    • "Фильтрация текстур" → Высокая производительность.
    • "Вертикальный синхроимпульс" → Выкл. (в игре тоже).

🔥 Для AMD:

  • В AMD Adrenalin → вкладка "Игры" → Dota 2 → настройте Radeon Anti-Lag и Radeon Boost (помогает при движении).
