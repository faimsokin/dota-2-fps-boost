1. Системные настройки

План питания

Выберите «Высокая производительность» в параметрах электропитания Windows.
Панель управления → Электропитание.

Отключить визуальные эффекты

Настройки быстродействия: «Обеспечить наилучшее быстродействие».
Система → Доп. параметры → Быстродействие.

Режим игры

Включите «Режим игры» в Windows и отключите запись фона (Game DVR).

2. Видео в Dota 2

Качество текстур

Установите «Среднее» или «Низкое». Отключите «Тени», «Окружающие эффекты», «Сглаживание».

Разрешение

Используйте разрешение экрана с понижением (например, 1600x900) для прироста FPS.

Эксклюзивный полноэкранный

Включите полноэкранный режим (не окно) для меньшей задержки.

3. Параметры запуска & консоль

Команды для консоли

cl_forcepreload 1
r_renderoverlayfragment 0
r_deferred_simple_light 0
r_dota_allow_screen_space_reflections 0

Добавьте в параметры запуска: -dx11 -threads 4 -high -novid -nojoy

5. Очистка и настройки ОС
  • Отключите ненужные фоновые приложения (автозагрузка).
  • Обновите драйверы видеокарты (чистая установка).
  • Отключите анимации в Windows (Система → Доп. параметры → Быстродействие).
  • Закройте браузер и программы во время игры.
1. System Settings

Power Plan

Set “High Performance” in Windows Power Options.
Control Panel → Power Options.

Disable visual effects

Performance settings: “Adjust for best performance”.
System → Advanced → Performance.

Game Mode

Enable “Game Mode” in Windows and turn off background recording (Game DVR).

2. Dota 2 Video Settings

Texture Quality

Set “Medium” or “Low”. Disable “Shadows”, “Ambient Effects”, “Anti-aliasing”.

Resolution

Lower resolution (e.g. 1600x900) for FPS boost.

Exclusive Fullscreen

Enable fullscreen (not windowed) for lower latency.

3. Launch Options & Console

5. OS Cleanup & Tweaks
  • Disable unnecessary background apps (startup).
  • Update GPU drivers (clean install).
  • Turn off Windows animations (System → Advanced → Performance).
  • Close browser and other apps while gaming.
